指示剂为什么这样选

要求只有一条：颜色变化必须发生在突跃范围之内。 突跃是 pH 4.3~9.7，只要指示剂在这个区间里变色，多滴或少滴那 0.02 mL 就能被看出来。

酚酞（8.2~10.0）和甲基橙（3.1~4.4）都满足 —— 变色范围窄、终点明显。 强碱滴强酸习惯用酚酞（无色→浅红，半分钟不褪色）；强酸滴强碱习惯用甲基橙（黄→橙）。

⚠️ 石蕊不能用于滴定。它的范围 5.0~8.0 其实也落在突跃里， 但它在这 3 个 pH 单位间由红渐变到蓝，中间全是说不清的紫色，终点根本判不准。 不是因为范围不对，是因为变色不灵敏 —— 这两个理由别搞混。

一个高频陷阱：恰好中和 ≠ 溶液呈中性

强酸 + 强碱恰好完全反应 → 生成的盐（如 NaCl）不水解 → 溶液确实是中性，pH = 7。 这一页算的就是这种情况。

但换成强酸 + 弱碱（如 HCl + NH₃·H₂O）：恰好完全反应生成 NH₄Cl， NH₄⁺ 会水解使溶液显酸性，pH < 7。 同理强碱 + 弱酸恰好中和后显碱性。

所以「恰好中和」说的是物质的量刚好反应完，不等于「溶液呈中性」。 这一页只做强酸强碱，弱酸弱碱要用电离平衡常数算，不在这一课范围内。

25 ℃、Kw = 1.0×10⁻¹⁴，强酸强碱按完全电离处理，忽略活度系数 —— 教材的标准简化。

pH 计算与突跃范围经脚本校验：滴入前 pH=1、恰好中和 pH=7、 ±0.1% 处 pH 4.30/9.70（与教材「突跃约 4~10」一致）、pH 随碱量单调递增 （0~40 mL 每 0.01 mL 逐点检查）。脚本在仓库里。
