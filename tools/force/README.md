# 力的合成 · 校验

`physics/force/` 那页的计算逻辑。页面 JS 与这里的 Python 是**两套独立实现**。

```bash
python3 verify_vectors.py
```

## 校验什么

7 道能手算的例题（3-4-5 直角、同向、反向、5N 夹 60°/120°、6-8-10、两个 10N 垂直），
比对余弦定理算出的合力大小；同时每道都用**按分量合成**再算一遍，两种算法必须一致。

另外还验：

- **合力范围** `|F₁−F₂| ≤ F ≤ F₁+F₂`：遍历 0~180° 每一度，合力都必须落在范围内，
  且 0° 取到上限、180° 取到下限（验了 5 组）
- **合力随夹角单调递减**（0°→180°，验了 3 组）

## ⚠️ 范围

只做**共点力**（两力作用于同一点）的合成。不在同一点的力还会产生转动效果（力矩），
不在这一课范围内 —— 页面上写明了。
