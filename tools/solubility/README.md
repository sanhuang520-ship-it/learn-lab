# 溶解度 · 数据与校验

`chemistry/solubility/` 那页的数据。

```bash
python3 verify_solubility.py data.json
```

## 校验什么

- 字段完整、11 个温度点（0~100 每 10 ℃）齐全、溶解度为正
- **单调性与 `trend` 字段一致**：标"下降"的必须单调递减（氢氧化钙），其余单调递增
- 关键考点数值：20 ℃ NaCl ≈ 36 g（易溶）、Ca(OH)₂ 在 0.01~1 g（微溶）
- 质量分数换算 `w = S/(100+S)`：恒 < 100%、随 S 单调递增
- 结晶方法判定：按 100 ℃ / 0 ℃ 的倍数，< 1.5 判蒸发结晶，否则降温结晶

## ⚠️ 数据来源

教学常用取值，与人教版九年级下册第九单元附表一致。
20 ℃：硝酸钾 31.6 g、氯化钠 36.0 g、氢氧化钙 0.165 g —— 写之前查证过。

## ⚠️ 绘图上的一个处理

氢氧化钙的溶解度只有 0.1 g 量级，和硝酸钾的 246 g 差三个数量级，
直接画会完全贴着横轴看不见。页面上**按放大 100 倍绘制**，
曲线末端标了 `×100`，表格里给的是真实数值 —— 不能让学生以为它真有那么大。
