# 孟德尔豌豆 · 遗传逻辑校验

`biology/mendel-pea/` 那一页的理论比例由棋盘法算出。页面里的 JS 和这里的 Python
是**两套独立实现**，这个脚本用来确认 Python 那套算得对。

```bash
python3 verify_genetics.py
```

校验两件事：
1. 6 种亲本组合的基因型比与表现型比，逐一比对人教版必修二的标准结论
2. 亲本互换（`DD×Dd` 与 `Dd×DD`）结果必须一致

## 这一页真正想教的

不是「3:1」这个数字，是**「3:1 是统计规律」**。
所以模拟用真随机、且提供 4 株这个刻意很小的样本 ——
学生点几次就会发现 4 株经常一株矮的都没有。
孟德尔当年统计上万株才敢下结论，这个体感比背结论重要。

## 容易记混的三点（页面上也写了）

- **3:1 是表现型比，1:2:1 是基因型比**。DD 和 Dd 长得一样。
- `Dd × dd → 1:1` 是**测交**，用途是检验一株高茎豌豆到底是 DD 还是 Dd。
- 样本小的时候偏离很大，那不是定律错了。
