# 酸碱滴定 · pH 计算与指示剂校验

`chemistry/titration/` 那页的计算逻辑。页面 JS 与这里的 Python 是**两套独立实现**。

```bash
python3 verify_titration.py
```

## 校验什么

关键点 pH（0.1 mol/L NaOH 滴 20.00 mL 0.1 mol/L HCl）：
滴入前 **1.00**、半中和 1.48、−0.1% **4.30**、恰好中和 **7.00**、+0.1% **9.70**、碱过量一倍 12.52。

另外验：
- pH 随碱量**单调递增**（0~40 mL 每 0.01 mL 逐点检查）
- 突跃范围（±0.1% 相对误差）约 **4.30~9.70**，与教材「强酸强碱滴定突跃约 pH 4~10」一致
- 指示剂可用性判定

## ⚠️ 指示剂判据我第一版写错了

第一版要求「变色范围**完全落在**突跃内」。结果：
石蕊（5.0~8.0）完全落在突跃 4.30~9.70 内被判为**最优**，
而酚酞（8.2~10.0）、甲基橙（3.1~4.4）因为端点越界被判**不合格** —— 与化学事实相反。

正确判据是两条：
1. 变色范围与突跃**有重叠**（颜色变化发生在 ±0.1% 误差内）
2. 变色要**灵敏明显**（范围窄）

石蕊被排除的理由是**第 2 条**：它在 3 个 pH 单位间由红渐变到蓝，中间全是紫色，终点判不准。
**不是因为范围不对。** 这两个理由页面上也特意分开写了。

## ⚠️ 范围

只做**强酸强碱**（完全电离）、25 ℃、Kw=1.0×10⁻¹⁴，忽略活度系数。
弱酸弱碱要用电离平衡常数，不在这一课 —— 页面上写明了，
并单独讲了「恰好中和 ≠ 溶液呈中性」这个陷阱（强酸弱碱盐会水解）。
