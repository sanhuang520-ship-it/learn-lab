# 摩尔计算 · 生成与校验

`chemistry/mole/` 那一页的题目来自这里。**题目由程序生成，答案由程序算** ——
手写题面再手写答案，迟早会对不上。

```bash
python3 gen.py              # 生成 problems.json（248 道）
python3 verify.py problems.json   # 独立重算校验
```

`verify.py` **不复用 gen.py 的中间结果**，它按题面文字重新解析、重新计算。
生成器算错了这里要能抓出来。

## 校验器查什么

1. 问「分子数」的题里不能出现离子化合物
2. 用到 22.4 L/mol 的题，物质必须是标况气体，且题面必须写明「标准状况」
3. 按题面独立重算答案，相对误差超 0.1% 就报错

## ⚠️ 两个真踩过的坑

**① 离子化合物没有分子。**
NaCl / CaCO₃ / NaOH / CuO / CuSO₄ 是离子化合物，问它们「含多少个分子」是化学错误，
老师会直接判错。物质表最后一列 `molecular` 就是为此存在的，
凡是问分子数的题只能从 `molecular=True` 里取。第一版没有这一列，生成出了
「0.25 mol 氢氧化钠含多少个分子」这种题。

**② 匹配物质名要按长度倒序。**
「硫酸」是「硫酸铜」的子串。校验器第一版用任意顺序取第一个匹配，
把 CuSO₄（M=160）的题当成 H₂SO₄（M=98）算，误报了 5 条。
