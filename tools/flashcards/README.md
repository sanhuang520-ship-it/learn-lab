# 反应闪卡 · 数据与校验

`chemistry/flashcards/` 那一页的卡片来自这里。

## 为什么要有校验器

化学方程式错一个就是教坏人。`check_equations.py` 对每条方程式做两件事：

1. **原子守恒** —— 展开化学式（支持括号、结晶水的 `·`），比对等号两边各元素原子数
2. **电荷守恒** —— 解析 `Ba(2+)` `SO4(2-)` 这类电荷写法，比对两边总电荷

跑一遍：

```bash
python3 check_equations.py cards.json
```

不守恒的会逐条打印哪个元素、左右各多少。

## 改数据

编辑 `cards.json`，字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，`localStorage` 用它记进度，**不要改已有的 id** |
| `cat` | `ion`（离子反应）/ `redox`（氧化还原）/ `class`（物质分类与转化） |
| `q` | 卡片正面：反应描述 |
| `hint` | 正面的提示，别直接剧透答案 |
| `eq` | 方程式，纯 ASCII 写法：下标直接写数字，电荷写 `(2+)` `(-)` |
| `note` | 翻面后的讲解，写易错点比写现象更有用 |

`eq` 写成 ASCII 是为了让校验器能解析；页面上显示的上下标（`Fe₂O₃`、`SO₄²⁻`）
由生成脚本转换，不用手写。

⚠️ 改完 `cards.json` 后**必须重新生成页面**，否则页面里内嵌的还是旧数据。

## 已知的坑

- 拆项只能按 ` + `（前后带空格）切，因为 `Ba(2+)` 里的 `+` 是电荷不是分隔符
- 教材版本差异（如铝与强碱：人教 `AlO2(-)` / 鲁科 `Al(OH)4(-)`）不要武断选一个，
  在 `note` 里两种都写清楚
