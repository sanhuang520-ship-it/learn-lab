# 电路求解 · 校验

`physics/circuit/` 那页的计算逻辑。页面 JS 与这里的 Python 是**两套独立实现**，
这个脚本用教材例题反查 Python 那套。

```bash
python3 verify_circuit.py
```

## 校验什么

5 道能手算的例题（两个 10Ω 串联、两个 10Ω 并联、6Ω∥3Ω 再串 2Ω、
三个 6Ω 并联、5Ω 串 15Ω），逐条比对总电阻与干路电流，另外每道都查：

- **串联各段分压之和 == 电源电压**
- **并联各支路分流之和 == 干路电流**
- 一条支路 0Ω 必须被识别为**短路**
- **并联总电阻恒小于任一支路**（初中反复强调的结论，验了 4 组）

## ⚠️ 范围与简化

只做**纯电阻**的串联、并联、以及「一段串一段并」的混联，
电源按**理想电源**（不计内阻）、导线电阻不计。这是初中电学的标准简化。

真实电路里电池有内阻，接近短路时端电压会明显下降，
不会像这里算出无穷大电流 —— **页面上写明了这一点**，不要让学生以为真会是 ∞。
