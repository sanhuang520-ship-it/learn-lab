# 电子排布 · 数据与校验

`chemistry/electron-shells/` 那一页的元素数据来自这里。

```bash
python3 verify_shells.py elements.json
```

校验四件事：
1. 排布不违反 R1–R5（每层 2n²、最外层≤8、次外层≤18、倒三层≤32、内层未满不外排）
2. 数据里的排布 == 按规则程序推导的结果
3. 电子总数 == 质子数
4. 周期数 == 电子层数；主族序数 == 最外层电子数

## ⚠️ R5 有个坑，改代码前先看

「内层没排满不能往外排」里的**「排满」有两种情况**：

- 装到了该层上限 2n²
- **装到 8 个就停** —— 因为它当时是最外层，再装就违反「最外层最多 8」

漏掉第二种，会把**钾的正确排布 `[2,8,8,1]` 误判成违规**（M 层能装 18，只装了 8）。
这恰恰是这一课最容易考的点：为什么钾是 2,8,8,1 而不是 2,8,9。

## 范围

只做 **1–20 号**。从 21 号钪开始 M 层才继续往上填（2,8,9,2），
那需要能级与构造原理，属于选修《物质结构与性质》，不在必修范围内。
要扩到 21+ 号，这套只依赖 2n² 与最外层规则的模型**不够用**，得换模型。
